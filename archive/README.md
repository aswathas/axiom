# Archive

Superseded material, kept for provenance and not for use.

## `pre-live-ui/`

Screenshots of the **original single-patient, pre-baked fixture UI**. Accurate as
a record of where the project started; misleading if presented as the current
product. They show one scripted patient and hardcoded claim text, with no upload,
no API, and no live refusal.

Current screenshots are in `screenshots/ui-*.png`, taken against the running
backend.

## `../docs/archive/`

- `AXIOM_D04_Pitch_Deck.pptx` / `AXIOM_D04_Full_Proposal.docx` — the original
  submission documents. They describe the static single-patient version of AXIOM
  and do **not** match the live system: no document ingest, no multi-patient
  list, no LLM prose extraction, and a different feature story.
- `UI_BUILD_PLAN.md` — the original frontend plan, written against
  `public/fixture.json`.

These were moved rather than deleted because they are someone else's work and
because the design reasoning in them is still worth reading. **Do not present
them as current.** If you need a deck for District 04, build it from
`README.md` and the live demo, not from these.
